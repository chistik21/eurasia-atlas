# Географические объекты мира

Статический интерактивный атлас для [GitHub Pages](https://chistik21.github.io/eurasia-atlas/): карта мира, 18 географических объектов и интересные факты о них. Установка зависимостей и сборка не нужны.

На телефоне карту можно двигать одним пальцем, менять масштаб двумя пальцами и приближать двойным касанием. На компьютере работают перетаскивание мышью и колёсико. Нажатие на номер объекта открывает информацию о нём.

Карта и оформление автоматически переключаются между светлой и тёмной темой по настройке устройства (`prefers-color-scheme`). Картинки `assets/world-map-light.svg` и `assets/world-map-dark.svg` включены в репозиторий, поэтому карта доступна без сторонних картографических сервисов. Контуры суши созданы на основе [Natural Earth, 1:110m land](https://www.naturalearthdata.com/about/terms-of-use/) (общественное достояние). Географические координаты точек ориентировочные.

Файлы `assets/map-base.webp`, `assets/eurasia-map.png` и `assets/eurasia-map.pdf` остались из исходного экспорта карты Евразии и больше не используются сайтом.
