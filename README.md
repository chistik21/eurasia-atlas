# Географические объекты Евразии

Готовый статический сайт для GitHub Pages. Сборка и установка зависимостей не нужны.

## Публикация

1. Распакуйте ZIP. Не загружайте сам ZIP в репозиторий: GitHub Pages его не распакует.
2. Создайте репозиторий на GitHub, например `eurasia-atlas`.
3. Загрузите содержимое распакованной папки в корень ветки `main`: `index.html`, `.nojekyll`, `README.md` и папку `assets` со всеми файлами. Не помещайте их во вложенную папку `github-pages-export`.
4. Откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем **Save**.
5. Дождитесь публикации; адрес появится на странице Settings → Pages. Для репозитория пользователя обычно это `https://USERNAME.github.io/eurasia-atlas/`.

Для загрузки через браузер: **Add file → Upload files**. На компьютере можно перетащить всю папку `assets`. На телефоне, если браузер не предлагает выбрать папку, сначала создайте файл `assets/placeholder.txt` через **Add file → Create new file**, зайдите в папку `assets` и загрузите туда пять файлов по отдельности.

Файлы `index.html` и `.nojekyll` должны лежать в корне репозитория; `app.js`, `style.css`, `map-base.webp`, `eurasia-map.png` и `eurasia-map.pdf` — внутри `assets/`.

Сайт работает без серверного кода. Координаты объектов — характерные точки протяжённых географических объектов; рельеф схематичен.
